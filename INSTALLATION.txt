EXCEL AGENT ADD-IN INSTALLATION GUIDE
======================================

PREREQUISITES
-------------

1. Microsoft Excel 2016 or later
2. Windows operating system
3. Internet connection (for API calls)

ENABLE TRUST ACCESS
-------------------

Before installing the add-in, you must enable trust access to the VBA project object model:

1. Open Excel
2. Go to File > Options
3. Click on "Trust Center" in the left panel
4. Click "Trust Center Settings..."
5. Click on "Macro Settings" in the left panel
6. Check the box: "Trust access to the VBA project object model"
7. Click OK to close all dialogs

INSTALL ADD-IN
--------------

Method 1: Manual Installation

1. Create a folder: C:\Program Files\ExcelAgent\
2. Copy ExcelAgent.xlam to this folder
3. Open Excel
4. Go to File > Options > Add-ins
5. At the bottom, next to "Manage:", select "Excel Add-ins"
6. Click "Go..."
7. Click "Browse..."
8. Navigate to C:\Program Files\ExcelAgent\
9. Select ExcelAgent.xlam
10. Click OK
11. The "AI Agent" tab will appear in the Ribbon

Method 2: Auto-Load Installation

1. Copy ExcelAgent.xlam to: %APPDATA%\Microsoft\AddIns\
   (Usually: C:\Users\[YourUsername]\AppData\Roaming\Microsoft\AddIns\)
2. Open Excel
3. Go to File > Options > Add-ins
4. The add-in should appear in the list
5. Make sure it's enabled
6. The "AI Agent" tab will appear in the Ribbon

CONFIGURE API
-------------

1. Click "Settings" in the AI Agent tab
2. Enter your API endpoint URL
3. Enter your API key
4. Select your model (e.g., gpt-4)
5. Click "Test Connection" to verify
6. Click "Save"

USAGE
-----

1. Click "Chat" in the AI Agent tab
2. Type a command in natural language (Indonesian)
3. Press Enter or click Send
4. The agent will generate and execute VBA code
5. Results will be shown in the chat

EXAMPLE COMMANDS
----------------

- Buat chart penjualan bulanan
- Format sel A1:F10 dengan warna biru
- Ekspor data ke PDF
- Buat sheet baru bernama Laporan
- Hitung rata-rata kolom B
- Tambah baris baru di tabel
- Hapus sheet yang tidak diperlukan

TROUBLESHOOTING
---------------

Problem: "Trust access to the VBA project object model" error
Solution: Follow the "Enable Trust Access" steps above

Problem: Add-in doesn't appear in Ribbon
Solution: Make sure the add-in is enabled in File > Options > Add-ins

Problem: API connection fails
Solution: Check your endpoint URL and API key in Settings

Problem: VBA code doesn't execute
Solution: Make sure macros are enabled in Excel

UNINSTALL
---------

1. Go to File > Options > Add-ins
2. Next to "Manage:", select "Excel Add-ins"
3. Click "Go..."
4. Uncheck ExcelAgent
5. Click OK
6. Optionally, delete the .xlam file from the installation folder
